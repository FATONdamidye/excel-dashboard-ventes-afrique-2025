# Dashboard Ventes Afrique 2025 — Excel

Dashboard interactif de suivi des performances commerciales
en Afrique, réalisé sous Excel avec tableaux croisés dynamiques.

## Aperçu

![Dashboard](screenshots/dashboard.png)

## Contexte

Analyse des ventes de 5 produits tech & agricoles sur 12 mois (2025),
couvrant 3 régions africaines, 5 commerciaux et 2000 transactions.

## KPIs principaux

| Indicateur | Valeur |
|---|---|
| Chiffre d'affaires total | 325 679 594 FCFA |
| Bénéfice total | 56 436 107 FCFA |
| Articles vendus | 10 835 |
| Nombre de transactions | 2 000 |

## Structure des données

| Feuille | Contenu |
|---|---|
| Données | Dataset brut — 2000 lignes |
| Traitement | Tableaux croisés dynamiques |
| Tableau de bord | Dashboard interactif |

## Outils utilisés

- Microsoft Excel
- Tableaux croisés dynamiques
- Graphiques dynamiques
- Segments (Slicers)
